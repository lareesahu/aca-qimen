# 鼠鼠阿仓奇门排盘 · 网页版

时家转盘 · 拆补法定局。奇门遁甲九宫排盘，纯前端计算，不联网、不上传。

原 Windows 桌面版（Electron，v0.64 测试版）里的 `index.html` 直接搬到网页：
同一套排盘逻辑、同样的九宫盘面，加上手机端排版、自托管字体（不再依赖飞书 CDN）、
PWA manifest 与离线缓存。

## 在线

https://lareesahu.github.io/aca-qimen/

## 本地

```bash
python -m http.server 8099
# http://127.0.0.1:8099
```

## 结构

- `index.html` — 全部界面与排盘逻辑（单文件）
- `assets/fonts/` — 思源宋体 / 思源黑体子集（woff2，自托管）
- `assets/icons/` — 图标（含 180 / 192 / 512 用于 PWA）
- `manifest.webmanifest`、`sw.js` — 可「添加到主屏幕」，二次打开走离线缓存


## 解盘（新）

盘面只给出符号，解盘给出读法。顶部「解盘」标签：

- **选问事**：事业、财运、感情、健康、考试、出行、官非、综合。用神随问事改变，同一局结论也跟着变。
- **断语卡**：一句话结论 + 用神落宫 + 方位 + 气数 + 所忌。
- **逐条看依据**：用神之门、九星、八神、宫与用神生克、四害（击刑/入墓/门迫/空亡）、月令旺衰、与日干宫和值符宫的关系、值使当门。每条都能展开看判定依据。
- **六步跟读**：从「这是阳遁几局」到「断语怎么落」，一步步教怎么读，可跳到盘面看对应宫位。

判定方法：用神落宫 → 门星神吉凶 → 宫与用神生克 → 四害 → 月令旺衰 → 与日干（己身）、值符（大势）的关系。健康一栏用「病星」作反向读（病星得势＝病重），不贴吉凶标签。

引擎在 `assets/jiepan.js`，独立于排盘逻辑；象意知识库沿用页面原有的 `MEN_INFO / XING_INFO / SHEN_INFO / GAN_INFO / GUA_INFO`，不另造条文。

## 趣味AI解读（模板库）

解盘页底部，四种风格各一条提示词：爽文小说版、说书先生版、重生归来版、一句判词版。

- 提示词由 `assets/jiepan.js` 的 `aiPrompt()` 现场拼装，**数据全部填好**：日干宫、时干宫、六合宫、乙/庚宫、生门/休门/开门/杜门 所临之神、四害、本局克应、用神与助忌计数。没有 `[占位符]`。
- `复制提示词` 走 `navigator.clipboard`（失败回落到 `execCommand`）；`丢给 ChatGPT` 用 `chatgpt.com/?q=` 直传，超过 7500 字符则改为复制后打开首页。
- 页面里没有任何 API key。若要「直接生成」，需另加同源代理（key 放服务端 env），不要在页面里加 key。
- 四版共用的红线：不断具体日期、不许诺结果、健康一律建议就医、末行「仅供娱乐」。
- 改文案后必须 `python tools/build-fonts.py`（字体子集是按页面实际用字生成的）。
